One full process-table scan costs ~6 seconds on this box, and the cold status path paid it five times. Every slow surface in the launcher — the 31-second status call, the 2-minute Edit screen, the 12-second CLI — is that single scan, multiplied. Nothing else burns: the GPU query, DNS, and install staleness were all measured and cleared.

01 · The fuel

What a scan actually costs

Enumerating all ~288 processes is free. Reading each one's command line is not — on Windows that's an OpenProcess + PEB read per pid, each taxed by Defender real-time protection.

Cleared suspects, measured: nvidia-smi spawn 0.06 s · getaddrinfo DNS stall ≤4 ms · stale editable install both installs at tip · mapped-drive visibility models on fixed NTFS. The per-scan cost is elastic — it doubles exactly when the box is busy, which is when status reads matter most.
